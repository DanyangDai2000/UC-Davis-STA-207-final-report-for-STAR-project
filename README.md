# Project STAR — 小班教学对幼儿园学业成绩的因果效应

一段回归分析项目：用 Project STAR 随机实验的原始数据，估计**小班教学**对幼儿园（K）学生阅读与数学成绩的因果效应，并分析效应的异质性、稳健性与时间持续性。

- 分析对象：**幼儿园 · 学生个体层面**
- 核心结论：小班显著提升成绩，助教班无可检测效应
- 正本报告：`report/STAR_project_report.md`
- 分析脚本：`analysis/star_kindergarten_analysis.R`

## 主结果

**政策效应（幼儿园，完整模型）**

- 小班：阅读 **+5.478** 分、数学 **+7.443** 分（p<0.001）
- 标准化效应量：Cohen's d = **0.18**（阅读）/ **0.16**（数学）
- 助教班：阅读 +0.721、数学 −0.272，**均不显著**

**教育公平效应（选择性）**

- 性别差距：阅读由 9.68 分缩至 4.55 分（**−52.95%**）、数学由 13.52 分缩至 2.27 分（**−83.19%**）
- 种族阅读差距：由 13.52 分缩至 10.08 分（**−25.42%**）；数学差距变化很小（−2.99%）
- 社会经济地位：交互项均不显著，SES 差距缩小有限（阅读 −6.77%，数学 −7.41%）
- 分位数回归：效应随能力水平递增（阅读 3.5 → 7.0 分，数学 5.0 → 14.0 分）

**时间持续性（§3.4，样本 N=2619）**

- 阅读：G1 **+6.27**\*\*、G3 **+4.26**\*\*；数学：G1 **+5.64**\*\*\*、G3 **+1.95**（不显著）
- 衰减率：阅读 **22%**、数学 **74%**
- 累积效应（4 年 vs 0 年）：阅读 **+3.90**\*\*

**稳健性（§3.5，七类检验）**

| 检验 | 小班效应 | 助教班效应 |
|---|---|---|
| 标准误设定（经典 / HC3 / 学校聚类） | 稳健（1% 水平显著） | 不显著 |
| 连续班级规模替代班型 | 稳健（阅读 −0.614 / 数学 −0.743，p<0.001） | — |
| 学校固定效应 | 稳健（阅读 6.427 / 数学 8.650） | 不显著 |
| 子样本（四类学校） | 系数全为正 | — |
| 极端值剔除（\|标准化残差\|>3） | 稳健（阅读 4.641 / 数学 7.154） | — |
| 多重插补（m=5，Rubin 合并） | 稳健（模型4 阅读 5.020 / 数学 6.703） | 不显著 |
| 伪实验（500 次校内重排） | 经验 p = **0.006**（阅读）/ **0.008**（数学） | — |

## 口径说明

- **标准误**：报告 §3.2 主表报告**经典标准误**；§3.5「标准误设定」另给出 HC3 异方差稳健与学校层面聚类（G=79）两种设定作对照，三种设定下小班系数完全相同（阅读 5.478、数学 7.443），只有标准误发生变化。
- **纵向样本**：§3.4 采用 K、G1、G2、G3 四期成绩均完整的学生（N=2619；控制变量缺失剔除后实际进入 2605 例），控制集与 §3.2 主模型（Model 4）一致。
